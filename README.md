# 折り紙シミュレーター

バージョン 1.2.0（変更内容は [CHANGELOG.md](CHANGELOG.md)）

ブラウザで紙を折って遊べる 3D 折り紙シミュレーターです。ビルド不要で、静的ファイルだけで動きます（three.js は `vendor/` に同梱）。

## 起動

ES Modules を使うため、ローカルサーバー経由で開いてください。

```sh
npm start            # = python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages などにそのまま置いても動きます。

## できること

画面の下のツールバーで、折り方をいつでも切り替えられます。

- **線を引いて折る**：紙の上をドラッグして折り線を引き、折りたい側をクリック
- **点を重ねて折る（点→点）**：動かしたい点（角など）を重ねたい点までドラッグ（その 2 点の垂直二等分線で折る）
- **谷折り / 山折り**
- **折り筋**：折ってすぐ開き、筋だけを残す。筋は紙の上に表示され、筋の端・交点・筋の線上に吸い付くので、筋を目印に折れる
- **袋をつぶす（つぶし折り）**：2 枚が折り目でつながった袋のつけ根に線を引き、袋をクリック。袋を開いて左右対称につぶす（正方基本形などが作れる）
- **中割り折り**：袋の途中に線を引き、先の側をクリック。先を内側に折り込む
- **全部の層 / 上だけ**：上だけのときは、クリックした所の一番上の部分と、その上に乗っている紙を一緒に折る（紙を突き抜けない）
- 角・辺の中点への吸い付き、`Shift` で 22.5° 単位の角度固定
- 折るときのアニメーション、元に戻す / やり直す、裏返す、90° 回す
- **手順ごとの開き具合スライダー**：途中まで開いた立体的な形も作れる
- 最初から再生、すべて開く / たたむ、手順をクリックしてその段階を表示
- **展開図**（山折り＝赤の一点鎖線、谷折り＝青の破線）を自動で表示
- 見本：三角、紙飛行機、屏風折り（扇）、たこ形、兜（かぶと）、セミ、鶴
  - 鶴は、展開図から物理シミュレーションで一度に折ります（スライダーで折り具合を変えられます）
- **BGM**：Web Audio でその場で作る和風の音楽（都節音階の琴の音＋持続音）。音楽ファイルは使っていません
- 紙の形（正方形 / A4 比 / 1:2）、表裏の色、模様（無地・方眼・青海波・水玉）
- マウス（右ドラッグで視点回転、ホイールで拡大）とタッチ（2 本指で回転・拡大）に対応

### キーボード

| キー | 動作 |
| --- | --- |
| `L` / `P` | 線 / 点→点 |
| `V` / `M` / `C` | 谷折り / 山折り / 折り筋 |
| `S` / `I` | 袋をつぶす / 中割り |
| `A` / `T` | 全部の層 / 上だけ |
| `F` | 裏返す |
| `R` | 90° 回す |
| `B` | BGM のオン・オフ |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Esc` | 折り線を取り消し |

## しくみ

- `js/paper.js` … 描画に依存しない幾何モデル。紙を凸多角形の面の集合として持ち、
  折り線で面を分割 → 動く側を鏡映 → 重なり順（layer）を更新します。
  各面は「自分を動かした手順」を覚えていて、手順ごとの角度で回転を合成して 3D の姿勢を求めます。
  展開図の山・谷は、隣り合う面の向きと重なり順から求めます。
- `js/main.js` … three.js による表示と操作（入力、アニメーション、UI）
- `js/presets.js` … 見本の折り方
- `js/sim.js` … 展開図から折る物理シミュレーション（鶴で使用）。
  辺の長さを保つばねと、折り線の角度を目標に近づけるねじりばねを解きます
  （[Origami Simulator](https://origamisimulator.org/) と同じ考え方を CPU で実装）。
- `js/bgm.js` … BGM（Web Audio API）
- `tools/svg-to-cp.mjs` … 展開図 SVG を `js/data/` のデータに変換するスクリプト

### 制限

平らに折る「単純な折り」（すべての層、または一番上／下のつながった部分を 1 本の直線で折る）を組み合わせて形を作ります。
つぶし折りと中割り折りは、平らな状態の間の動きとして計算しています（途中のアニメーションでは、紙が一瞬重なって見えることがあります）。
花弁折りや沈め折りにはまだ対応していないため、鶴は展開図からのシミュレーションで折っています。
