    使い方

    • 線：紙の上をドラッグして折り線を引き、折りたい側をクリック。
    • 点→点：動かしたい点（角など）を、重ねたい点までドラッグ。
    • 折り筋：折ってすぐ開き、筋だけ残します。筋の端・交点・筋の上にも吸い付きます。
    • 袋をつぶす：2 枚が折り目でつながった「袋」のつけ根に線を引き、袋をクリック。袋を開いて左右対称につぶします。
    • 中割り：袋の途中に線を引いて、先の側をクリック。先を内側に折り込みます。
    • 上だけ：クリックした所の一番上の部分を折ります。その上に乗っている紙も一緒に折れます（紙を突き抜けないように）。
    • 角や辺の中点には自動で吸い付きます。Shift で角度を 22.5° 単位に。
    • 右ドラッグ／2 本指で視点を回転、ホイール／ピンチで拡大縮小。
    • L 線 / P 点→点 / V 谷 / M 山 / C 折り筋 / S 袋をつぶす / I 中割り
    • A 全部の層 / T 上だけ / F 裏返す / R 回す / B BGM / Esc 取り消し
